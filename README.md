# Le Code et la Cybersécurité de A à Z

Parcours statique pour apprendre progressivement le développement et la cybersécurité.

HTML → CSS → JavaScript → Python → Git/GitHub → SQL → Réseaux → Linux → Cybersécurité → Cryptographie → Sécurité web → OSINT → Analyse → Projet final.

Les exercices de sécurité sont destinés à des environnements autorisés et à des données fictives.

## GitHub Pages
Dans **Settings → Pages**, sélectionner la branche **main** et le dossier **/ (root)** puis enregistrer.
