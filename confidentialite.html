INFORMATIONS DU SITE

Confidentialité et données locales

Cette page explique les fonctions de stockage côté navigateur visibles dans le code du site. Elle ne constitue pas une garantie juridique ni un audit indépendant de tous les composants.

Quelles données peuvent rester dans ton navigateur ?

  • La progression d’apprentissage et les résultats utilisés par les fonctions de cours ou de quiz.
  • Le thème d’affichage choisi et le mode de lecture renforcée.
  • Des préférences et états locaux nécessaires aux fonctions interactives.

Ces données locales peuvent être différentes selon le navigateur et l’appareil. Le site ne fournit pas de compte utilisateur ni de synchronisation cloud intégrée à ce tableau de bord.

Exporter ou effacer la progression

Dans Ma progression, utilise l’export pour conserver une copie du fichier de sauvegarde. L’import doit être réservé à un fichier que tu comprends et que tu souhaites restaurer.

Le bouton de réinitialisation efface les clés locales de progression reconnues par le site sur ce navigateur et conserve les préférences de thème et de lisibilité. Cela n’efface pas les fichiers déjà exportés, l’historique du navigateur ou les données conservées ailleurs.

Conseils de sécurité

  • N’entre jamais de vrai mot de passe, clé API, jeton ou donnée personnelle dans les exercices.
  • Les exercices de cybersécurité sont destinés à des environnements fictifs ou explicitement autorisés.
  • Sur un appareil partagé, ferme la session du navigateur et évite d’y conserver une sauvegarde personnelle.

Limites

Le stockage local peut être supprimé par le navigateur et n’est pas une sauvegarde fiable. Cette page décrit les fonctionnalités de stockage prévues dans le code ; elle ne certifie pas l’absence de toute requête réseau ou de tout composant tiers sur chaque page.
