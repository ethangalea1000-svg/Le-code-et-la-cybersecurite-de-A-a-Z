DÉFI GUIDÉ

Défi 01 · Personnalise une carte

  1. Remplace le titre par celui de ton mini-projet.
  2. Change la couleur de fond de la carte dans le CSS.
  3. Modifie le message affiché au clic dans le JavaScript.
  4. Lance l’aperçu et vérifie que les trois modifications fonctionnent.

Indice : le HTML décrit le contenu, le CSS son apparence et le JavaScript son comportement.
