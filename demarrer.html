Le code, c'est quoi ?

Le code est une liste d'instructions écrite pour un ordinateur, comme une recette de cuisine. L'ordinateur la suit exactement.

Exemple : <h1>Bonjour</h1> dit au navigateur d'afficher un grand titre avec le mot Bonjour.

Avec le code, tu peux créer des sites, des jeux et des programmes, puis comprendre comment les systèmes se protègent : c'est la cybersécurité.

Ce que tu vas apprendre, étape par étape

HTML pour la structure, CSS pour le style, JavaScript pour l'interaction. À la fin de ces cours, tu sais construire une vraie page web qui réagit.

Comment le site fonctionne

1

Des leçons courtes

Chaque leçon suit quatre petites étapes : tu lis l'essentiel, tu réponds à une question, tu testes du code, tu fais un mini-défi. Environ cinq minutes par leçon.

2

Tu pratiques tout de suite

Un laboratoire de code est intégré à chaque leçon. Tu n'installes rien : tout se passe dans ton navigateur.

3

Ta progression est gardée

Pas de compte ni de mot de passe : tes leçons validées et tes XP sont enregistrés dans ton navigateur, sur l'appareil que tu utilises.

4

Un mot te bloque ?

Le glossaire explique chaque mot technique en une phrase simple, et le mentor te donne des indices pendant les leçons.

Ton premier pas

Conseil : suis les cours dans l'ordre, chacun réutilise les notions du précédent. La première leçon te fait écrire ta première ligne de code en quelques minutes.
